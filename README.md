# Вэрн

Прототип торговой площадки в оболочке фэнтезийного мира.
Работает внутри Телеграма как мини-приложение и в обычном браузере.

- `/` — создание героя: народ, облик, свободное описание, портрет
- `/мир/` — мир-витрина: кольца рынка, лавки, столы, шахматы

Сервера нет. Герой сохраняется в браузере того, кто его создал,
обитатели мира вымышленные.

Портреты генерирует Pollinations. Правила шахмат — chess.js,
лицензия BSD-2-Clause.
